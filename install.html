ONECOPY Files через бесплатный Pyto

Если Face ID сломан, а защита украденного устройства установлена в режим «Всегда», установка DNS-профиля может быть заблокирована. Ниже — альтернатива для сканирования папок без подписи IPA: бесплатный Pyto из App Store запускает наш отдельный сканер ONECOPY.

Скрипт проверяет несколько выбранных папок со всеми вложениями, вычисляет SHA-256, подтверждает совпадения побайтово и сохраняет отчёт CSV. Он ничего не удаляет.

Пошаговый запуск и ограничения

Это НЕ нативный ONECOPY 0.3: нет автоматического доступа к фото/видео из «Фото», нет удаления и нет доступа к закрытым папкам iOS. Алгоритм проверен локально, но не на реальном телефоне. Для фото и видео используй «Фото» → «Коллекции» → «Другое» → «Дубликаты».

Бесплатная альтернатива №1 · iOS 27

AltLoad: установка прямо с iPhone

Разработчик AltLoad предлагает 32 варианта подписанной установки с публичными сертификатами. Действительность каждого на твоём устройстве не подтверждена — если сертификат отозван, установка не запустится.

  1. В Safari открой официальный AltLoad, прими условия и установи DNS-профиль согласно инструкции автора.
  2. В блоке «Pick a signed install» попробуй предложенный вариант. Если приложение не установится или не откроется после доверия профилю, этот сертификат может быть отозван.
  3. Если AltLoad запустился, включи Developer Mode в настройках iPhone, затем Tools → Pair и выполни инструкцию по коду сопряжения.
  4. Установи бесплатный LocalDevVPN из App Store и включи туннель согласно руководству AltLoad.
  5. В AltLoad: Install → меню «…» → Install IPA from Files. Выбери скачанный ниже ONECOPY IPA и выполни подпись через бесплатный Apple ID. Подпись истекает через 7 дней и требует продления.
Попробовать официальный AltLoad

Никакие сертификаты или пароли Apple ID не нужны нашей веб-странице. Используй только оригинальный проект автора — поддельные копии могут красть учётные данные.

Бесплатная альтернатива №2 · без публичных сертификатов

iSH + свой бесплатный сертификат Apple

Автор SideInstaller разработал самостоятельную процедуру: iSH из App Store собирает подписывающую программу и использует собственную бесплатную подпись Apple, чтобы установить SideInstaller и затем ONECOPY. Этот путь не зависит от массово отозванных корпоративных сертификатов, но экспериментальный: сама установка через локальный HTTPS-сервер не подтверждена разработчиком на всех реальных устройствах.

  1. Установи iSH из App Store.
  2. Открой официальную инструкцию автора. Перед запуском ознакомься с кодом, потому что он обрабатывает данные для входа в Apple ID.
  3. Следуй инструкции iSH. После успешной установки SideInstaller импортируй наш IPA, доступный ниже.

Другие проверенные варианты

Подписывающие приложения и сертификаты

  • Scarlet, сайт разработчика: прямой установщик с общими сертификатами, но текущая работоспособность на iOS 27 не подтверждена. Не путать с неофициальными клонами.
  • Feather, KSign и ESign: умеют подписывать IPA прямо на iPhone, но нужны действительные P12 + provisioning profile.
  • NexCerts: общедоступные сертификаты с P12 сейчас помечены как отозванные; несколько действительных сертификатов показаны без P12, поэтому подписать ONECOPY ими нельзя.
  • BreakFree: экспериментальный метод с публичными корпоративными сертификатами и DNS, последняя заявленная проверка — iOS 26.5, работа на iOS 27 не подтверждена.
  • AltCert (от €7), FlareStore (от ~$3, в зависимости от тарифа) и Signulous ($19,99 в год): коммерческие варианты регистрации iPhone и подписи, без компьютера. Цена и сроки могут измениться; услуги не проверены на нашем устройстве.
Не устанавливай сертификат от незнакомого источника только потому, что он отмечен как «Valid»: нужен и подходящий профиль для твоего устройства, и честное происхождение подписанного приложения. После настройки удаляй ненужные DNS/конфигурационные профили.
Шаг 1

Установи SideInstaller

  1. Открой официальный сайт SideInstaller в Safari и проверь, появился ли действующий сертификат.
  2. Если опубликованные сертификаты окажутся отозванными, не устанавливай сомнительные зеркала и профили. Можно ознакомиться с резервным способом через iSH, но разработчик прямо предупреждает, что он не полностью проверен на физических устройствах.
  3. Если установщик доступен, следуй официальным инструкциям по DNS/VPN и профилю. Сначала оцени риски: профили меняют сетевые настройки, сертификаты могут быть отозваны.

После установки

Запуск и разрешения

  1. Открой ONECOPY на iPhone.
  2. Разреши доступ ко всей медиатеке «Фото», если хочешь проверить всю доступную медиатеку.
  3. В разделе «Файлы» добавь папки, которые программа должна проверять.
  4. Нажми «СКАНИРОВАТЬ», затем проверь найденные группы.
ONECOPY 0.3 — тестовая сборка: запуск в симуляторе проверен, а безопасное массовое удаление на реальном iPhone — нет. Не удаляй важные оригиналы. Ни одно обычное iOS-приложение не может читать все системные папки телефона.
