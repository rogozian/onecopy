# ONECOPY

**ONECOPY** — независимый проект для поиска побайтово идентичных файлов. Исходники и автоматические сборки находятся в этом репозитории. Никаких Higgsfield SDK, регистрации или платных библиотек.

## ONECOPY для iPhone — бесплатно и без установки

После активации GitHub Pages: **https://rogozian.github.io/onecopy/**

Открой ссылку на iPhone через Safari. Нажми большую кнопку **«СКАНИРОВАТЬ»**, выбери фотографии, видео или файлы, и ONECOPY локально сгруппирует точные копии. В каждой группе выбирается файл, который нужно оставить; остальные попадают в список для ручной проверки. Чтобы добавить иконку: Safari → «Поделиться» → «На экран “Домой”».

**Важное ограничение:** веб-версия **не имеет права просматривать всю медиатеку iPhone или удалять файлы без выбора пользователя**. Кнопка сканирования открывает системный выбор материалов. Safari иногда преобразует фотографии при экспорте, поэтому проверяется версия, переданная браузеру. Выбор «оставить» не удаляет другие экземпляры; полный список можно скопировать или экспортировать в CSV. На сервер файлы не загружаются.

## Как сравниваем

1. Группируем выбранные файлы по полному размеру в байтах.
2. Для файлов одинакового размера вычисляем выборочный SHA-256 по трём участкам, чтобы ускорить проверку. Если Web Crypto недоступен, эта оптимизация пропускается.
3. Окончательный ответ «дубликат» даём **только после сравнения всех байтов** двух файлов блоками по 1 МиБ.
4. Не используем имена файлов, даты, расширения или похожесть картинок в качестве доказательства идентичности.

Система не обещает, что размер копий соответствует физически освобождаемой памяти; метаданные, размещение в iCloud, APFS и альбомы могут различаться.

## Нативные программы

- `macos/` — SwiftUI-приложение для Mac (исходники, тесты, сборка .app/.dmg через GitHub Actions). Дистрибутивы QA подписаны ad hoc, **не нотарифицированы Apple**.
- `ios/` — SwiftUI-приложение iOS (исходники, сборка для симулятора и физического устройства без подписи, QA). **Неподписанный .ipa не устанавливается напрямую на iPhone**. Для TestFlight нужна разрешённая подпись Apple.

Это независимые версии и они не зависят от веб-хостинга.

## Проверка

```sh
node --test tests/scan.test.mjs
node --check app.mjs
node --check scan-engine.mjs
```

Для UI smoke-тестов нужен Chromium/Playwright, используется `python tests/ui-smoke.py` (не требуется для работы приложения). Изменения в `main` автоматически запускают проверки веб-сканера и сборки Apple. Ветка `main` является исходным кодом, не содержит секретов и сертификатов.

## Автопубликация

`.github/workflows/pages.yml` проверяет код, создаёт минимальный набор статических файлов и развёртывает его через GitHub Pages. Для **первого** запуска GitHub Pages владелец репозитория должен открыть `Settings → Pages → Build and deployment → Source → GitHub Actions`, если сервис ещё не включён.

### iOS: исправления в исходниках 0.3 (QA)

Нативная версия теперь содержит единый стартовый сканер для доступной медиатеки и добавленных пользователем папок, пакетную выборку проверенных повторов «Фото», полноэкранный просмотр и Quick Look документов, межпапочный поиск и список путей. Это **не** возможности веб-версии и **не** готовая подписанная установка. Веб-версия по-прежнему может проверять только вручную выбранные файлы.


### Установка через SideInstaller (iPhone, без Mac)

[**Пошаговая страница ONECOPY**](https://rogozian.github.io/onecopy/install.html) предлагает установку через `sideinstaller://install?url=...` после установки официального SideInstaller. Источник IPA — [наш GitHub Release](https://github.com/rogozian/onecopy/releases/tag/ios-qa-0.3). Если официальный сайт показывает 0 действующих общих сертификатов, стандартный bootstrap SideInstaller недоступен; не используйте неофициальные зеркала. Подпись и проверка на реальном iPhone остаются обязательными, тестовая IPA сама по себе не устанавливается.
