# ONECOPY Files для Pyto — без профилей и Face ID

Этот вариант запускает **сканер файлов ONECOPY внутри бесплатного приложения [Pyto IDE](https://apps.apple.com/app/pyto-ide/id1436650069)** из App Store. Это НЕ установка нативной ONECOPY 0.3 IPA. Нет DNS-конфигураций, подписи IPA, Mac, платного аккаунта Apple Developer.

## Запуск на iPhone

1. Установи [Pyto IDE](https://apps.apple.com/app/pyto-ide/id1436650069) из App Store. Базовая версия бесплатная, возможны встроенные покупки. Если магазин использует неисправный Face ID, [Apple описывает авторизацию через пароль Apple Account](https://support.apple.com/ru-ru/119848), хотя доступность переключения нужно проверять при включённой защите «Всегда».
2. В Safari открой [ONECOPY_Files_Pyto.py](https://raw.githubusercontent.com/rogozian/onecopy/main/fallback/ONECOPY_Files_Pyto.py) и сохрани файл в «Файлы» (через меню «Поделиться» или загрузку).
3. Открой его из файлового браузера Pyto и нажми **Run**.
4. Выбери папку. Скрипт рекурсивно проверяет подпапки. Чтобы добавить вторую папку, введи `+` и Enter; просто Enter запускает проверку.
5. ONECOPY сравнит размеры, SHA-256 и сами байты, затем покажет группы дубликатов и сохранит CSV-отчёт в Documents Pyto. **Сам он ничего не удаляет**.

## Ограничения

- Только папки, доступ к которым ты дал через системный выбор папки. Закрытые папки iOS не доступны.
- Файлы iCloud и сторонних провайдеров, которые физически не доступны, могут быть пропущены. Их пути и ошибки включаются в CSV.
- Фотографии и видео из приложения «Фото» скрипт не сканирует. Для них доступно системное «Фото» → «Коллекции» → «Другое» → «Дубликаты».
- Внешнее приложение Pyto может иметь ограничения бесплатного режима.
- Алгоритм проверен шестью локальными автоматическими тестами на тестовых файлах; на физическом iPhone с Pyto **ещё не проверен**.

## Безопасность

Только чтение: никаких сетевых запросов, удаления, перемещения или изменений файлов. Это временный функциональный обходной вариант для папок, а не полноценный релиз ONECOPY iOS 0.3.
