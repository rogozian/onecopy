# ONECOPY — независимый проект

Это самостоятельный веб-клиент ONECOPY. Программа написана на обычных HTML/CSS/JavaScript, без Higgsfield SDK, без платных библиотек, без авторизации у вендоров, без запросов к удалённому API. Может находиться в отдельном GitHub-репозитории пользователя и размещаться на любом HTTPS-статическом хостинге. Старый хостинг был лишь временным экспериментом, не является зависимостью новой программы и не нужен для дальнейшей разработки.

Создание GitHub-репозитория и публикация GitHub Pages требуют действительных прав на аккаунт. Через доступные сейчас GitHub-действия можно работать с существующими репозиториями, но нельзя создать новый. ONECOPY не должен добавляться в несвязанные репозитории.
