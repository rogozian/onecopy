# ONECOPY — безопасный поиск точных дубликатов на macOS

**Версия:** 0.2, усиленный пилот для локальной проверки. **Платформа:** macOS 13+ (Ventura, Sonoma, Sequoia и более новые версии). Исходный код Swift, нативный интерфейс SwiftUI.

Главный принцип: **программа не удаляет файлы автоматически**. Находит **только побайтово одинаковые файлы** — независимо от имени, расширения и расположения — и предлагает выбрать, какой экземпляр оставить. Остальные попадают **в системную Корзину**, откуда их можно восстановить.

## Сборка и запуск на вашем Mac

**Самый короткий путь:** разархивируйте проект, затем откройте `Запустить-ONECOPY.command` (при установленных инструментах разработчика он выполнит тесты, соберёт приложение и откроет его). При проблемах с запуском `.command` следуйте шагам ниже.

1. Скачайте ZIP с исходниками, разархивируйте (например, в «Загрузки»).
2. Если на Mac ещё нет Swift, однократно установите Apple Command Line Tools, введя в «Терминале» `xcode-select --install` и подтвердив установку.
3. Откройте «Терминал», введите `cd ` (с пробелом), перетащите в окно Терминала папку `onecopy-macos` и нажмите Enter.
4. Выполните: `bash scripts/package-macos.sh`
5. После прохождения тестов откройте приложение: `open dist/ONECOPY.app`. Впоследствии можно переместить `dist/ONECOPY.app` в папку «Программы».

Альтернативный путь: открыть `Package.swift` в Xcode 15+ и запустить схему OneCopy. При публикации кода в GitHub можно получить архив приложения в **Actions → Build ONECOPY for macOS → Artifacts** (автоматизация сборки уже входит в проект).

**Примечание:** версия 0.2 прошла 17 автоматических тестов ядра в Linux-среде. Однако **полноценная macOS-сборка и интерфейс ещё не проверены на реальном Mac**. Первый запуск следует считать пилотным тестированием. Не начинайте с важных или рабочих документов, пока не убедитесь, что перемещение и восстановление работают на вашей конфигурации.

## Как использовать

1. Нажмите **Добавить папки**. Для первой проверки выберите тестовую папку или «Загрузки». Можно добавить несколько папок, если копии лежат в разных местах.
2. Нажмите **Найти одинаковые**. Поиск только читает файлы, ничего не меняет.
3. В каждой найденной группе откройте файлы в Finder, выберите экземпляр **ОСТАВИТЬ** и поставьте галочку рядом с нужной группой. По умолчанию группы **не выбраны**.
4. Нажмите **В Корзину**, подтвердите. Перед каждой операцией приложение заново проверяет содержимое обеих копий и то, что файлы не изменились после сканирования.
5. При необходимости откройте **История и восстановление** либо Корзину Finder. Программа **не очищает Корзину** за вас.

## Как определяются дубликаты

- Поиск только в выбранных папках. Системные области, `~/Library`, скрытые файлы, пакеты приложений и фотографий, символические ссылки и рабочие папки `.git` / `node_modules` пропускаются.
- Сначала отсев по размеру файла. Далее сравниваются небольшие фрагменты файла (быстрый фильтр), затем вычисляется SHA-256 всего файла, затем проверяются все байты при формировании группы.
- Сразу перед отправкой в Корзину проверка повторяется **побайтово**. Дополнительно сравниваются размер, время последнего изменения и идентификатор файла в файловой системе.
- Разные жёсткие ссылки (hard links) на один inode не считаются отдельными физическими копиями. При сомнениях о количестве ссылок очистка блокируется.
- Перед перемещением сравниваются POSIX-права, владелец/группа, расширенные атрибуты macOS (включая Finder tags и resource forks), а также наличие расширенных ACL и flags. Если свойства различаются или нельзя их прочитать, очистка блокируется и остаётся только просмотр.
- Файлы из облачных и сетевых расположений пропускаются, чтобы не загружать их из сети и не инициировать синхронизированное удаление.
- Нулевой размер файлов допускается: пустые файлы тоже могут совпадать, но не дают ощутимого выигрыша.

## Важные ограничения

- Утилита **не** ищет «похожие» фото, перекодированные видео, версии документов или визуально одинаковые PDF с различающимися метаданными. Это намеренное правило безопасности.
- Любая очистка в Корзину не увеличивает доступное пространство сразу: для этого Корзина должна быть опустошена **вручную**, после проверки результата.
- Сканирование больших видео и сетевых дисков занимает время, потому что содержимое реально читается. Некоторые облачные файлы могут скачаться по требованию ОС. В первой версии лучше проверять только локальные папки.
- На APFS клоны могут разделять физические блоки, поэтому сумма логических размеров найденных копий **не равна** гарантированному освобождению физического пространства.
- При изменении файлов другими программами во время работы **по-прежнему нет атомарной гарантии** против гонки между финальной проверкой и переносом в Корзину. Отдельные приложения могут ссылаться на путь или идентификатор файла; SHA-256 и побайтовая идентичность не доказывают взаимозаменяемость таких файлов. Поэтому пилотная версия ограничивается выбранными папками, подтверждением пользователя и Корзиной.
- История восстановления ведётся локально: `~/Library/Application Support/OneCopy/trash-history.json`. Восстановление требует, чтобы файл оставался в Корзине и исходный путь был свободен.
- Для некоторых папок macOS запросит разрешение на доступ. Это штатное системное ограничение.
- Сборка подписана только **ad hoc**, а не Apple Developer ID. Для широкого распространения потребуется официальная подпись и нотариализация Apple.

## Приватность

Нет серверных запросов, аккаунтов, аналитики или внешних зависимостей. Файлы никогда не отправляются куда-либо. Все проверки происходят на локальном устройстве.

## Развитие

Ближайшие задачи: подписанная и нотариализованная сборка, измерение реально освобождённых APFS-блоков, обработка внешних носителей, исключения и фильтры, проверка облачных placeholders, превью файлов Quick Look, единый кроссплатформенный движок для Windows/Linux/Android.


## Изменения в 0.2

- Три категории: допустимо к ручному перемещению, нужна проверка (без удаления), защищено (без удаления).
- Полная проверка метаданных через C interop для macOS, включая ACL и extended attributes.
- Защита от устаревших результатов, hard links и файлов с изменившимися метаданными.
- Всего **17 успешных тестов на Linux** (включая подмену файлов, различия прав, изменение содержимого, символические ссылки).
- Это всё ещё **не нотариализованная и не проверенная на Mac** сборка. Сначала проверяйте только на тестовых папках.
