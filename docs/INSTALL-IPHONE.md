# Как запустить нативную ONECOPY на iPhone

**Статус на 9 ноября 2026:** ONECOPY iOS 0.3 QA собрана в GitHub Actions. Тестовая IPA **не подписана Apple**, поэтому нажатие на файл из Safari **не устанавливает** приложение.

## Где взять оригинальный IPA

- [Релизы ONECOPY](https://github.com/rogozian/onecopy/releases) — только оригинальный файл из нашего репозитория. Для QA выбирайте файл `ONECOPY-iPhone-UNSIGNED-NOT-INSTALLABLE.ipa`.
- [Исходный код iOS](https://github.com/rogozian/onecopy/tree/main/ios).
- [Результаты тестов и сборок](https://github.com/rogozian/onecopy/actions).

## Вариант A: только iPhone, без компьютера — платная сторонняя подпись

1. В Safari откройте https://www.signulous.com/register .
2. Регистрация iPhone и подпись собственного IPA стоят **$19.99 за год** по данным официального сайта на дату проверки. Это сторонняя услуга, НЕ плата за ONECOPY и НЕ Apple Developer Program.
3. Дождитесь активации регистрации устройства и откройте панель подписи Signulous.
4. Загрузите оригинальный IPA из GitHub Releases, выполните `Sign App` → `Install App`.
5. При необходимости подтвердите доверие к профилю приложения и включите режим разработчика в настройках iPhone.

Сертификат могут отозвать; сроки активации и доступность не гарантированы. Не передавайте пароль Apple ID посторонним сайтам. Не загружайте в сервис собственные фото и документы: для подписи нужен только программный IPA.

## Вариант B: бесплатно, iOS 27, без компьютера — если заработает SideInstaller

- Официальный проект: https://github.com/FrizzleM/SideInstaller , https://sideinstaller.net/ .
- Его разработчик описывает установку SideStore прямо с iPhone на iOS 27. После настройки SideStore можно подписать наш IPA бесплатным Apple ID; Apple ограничивает срок подписи семью днями и число приложений.
- **На проверенную дату 7 ноября 2026** официальный сайт показывал `0 currently valid` из 22 сертификатов для первоначальной установки. Если там всё ещё ноль — не тратьте время на установку: маршрут заблокирован.
- Установка вспомогательного ПО с общими корпоративными сертификатами и DNS-профилями несёт риски. Не устанавливайте зеркала и не вводите пароль Apple ID в неизвестные приложения.

## Вариант C: бесплатно, если можно одолжить компьютер один раз

- Через официальный Xcode на Mac, либо AltStore/SideStore/Sideloadly на Mac или Windows.
- Обычный бесплатный Apple ID подписывает и запускает приложение на собственном телефоне, но профиль обычно истекает через **7 дней**, а для продления нужна повторная подпись. SideStore после первичной настройки поддерживает обновление с iPhone.
- Официальная документация Apple: https://developer.apple.com/help/account/basics/about-your-developer-account .

## Когда приложение установлено

Откройте ONECOPY → разрешите **полный доступ к Фото** → нажмите большую кнопку **«СКАНИРОВАТЬ»**. Фото проверяются в рамках разрешённой медиатеки, а документы — только в папках, добавленных пользователем на вкладке «Файлы». Найденные копии открываются на соответствующих вкладках.

**Важная граница:** весь iPhone, включая контейнеры других приложений и системные файлы, не доступен ни одному обычному iOS-приложению. Версия 0.3 — QA: до реальных испытаний не используйте пакетное удаление для незаменимых данных. Никакой из способов установки не расширит системные разрешения iOS.

## Что точно НЕ работает

- Нельзя установить неподписанную `.ipa` просто по ссылке в Safari.
- GitHub Pages — это веб-версия Web Lite, а не нативное приложение.
- Бесплатное членство Apple Developer само по себе не даёт TestFlight.
- Альтернативный маркетплейс ЕС не позволяет загрузить произвольный неподписанный IPA без требований Apple к разработчику и нотарификации.
